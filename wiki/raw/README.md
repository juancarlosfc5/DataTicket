# Fuentes crudas

Carpeta para fuentes originales **inmutables**: actas de reunión, prototipos (`DataTicket.html`), el borrador `mvp-sistema-tickets.md`, el ZIP de diseño, capturas, etc. Los adjuntos van en `raw/assets/`.

Para incorporar una fuente: déjala aquí y pide al agente *"ingiere `raw/<archivo>`"*. El agente creará su resumen en `fuentes/` y actualizará las páginas afectadas (ver `AGENTS.md` §5.4). La fuente principal, `PRD.md`, vive en la raíz del repositorio.
